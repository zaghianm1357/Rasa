# RASA — Replay Foundation v0.1

این بسته، زیرساخت اولیه بازپخش تاریخی RASA است؛ هنوز تشخیص Swing / Liquidity Sweep / CHoCH در آن پیاده‌سازی نشده است.
هدف این نسخه تثبیت قرارداد داده، ترتیب زمانی، کنترل جلسه معاملاتی، جلوگیری از نگاه به آینده و اجرای تکرارپذیر است.

## پیش‌نیاز
- Python 3.10 یا جدیدتر (با Python 3.14 نیز سازگار است)
- بدون نیاز به نصب کتابخانه جانبی

## ساختار ورودی
برای هر تایم‌فریم یک CSV مستقل:
`timestamp,open,high,low,close,tick_volume,spread`

- timestamp زمان بازشدن کندل است.
- زمان باید ISO-8601 و دارای timezone باشد؛ برای نمونه `2026-11-20T19:39:00+00:00`.
- زمان بدون timezone عمداً رد می‌شود؛ چون timezone داده‌های تاریخی هنوز نباید حدس زده شود.
- فایل‌های خام تغییر داده نمی‌شوند.

## اجرا
در پوشه‌ای که فایل‌ها را استخراج کرده‌اید:

```powershell
python -m rasa_replay --h1 "DATA\XAUUSD_H1.csv" --m15 "DATA\XAUUSD_M15.csv" --m1 "DATA\XAUUSD_M1.csv"
```

اختیاری:
```powershell
python -m rasa_replay --h1 "DATA\H1.csv" --m15 "DATA\M15.csv" --m1 "DATA\M1.csv" --start "2026-11-20T00:00:00+00:00" --end "2026-11-21T00:00:00+00:00"
```

## خروجی
- `output/replay_events.jsonl`: رویدادهای کندل به ترتیب زمانی
- `output/replay_summary.json`: خلاصه اجرا و کنترل‌های کیفیت

## محدودیت‌های عمدی این نسخه
1. این نسخه هیچ سفارش معاملاتی ایجاد نمی‌کند.
2. هیچ Alert معاملاتی صادر نمی‌کند؛ فقط رویدادهای داده را بازپخش می‌کند.
3. Tick replay هنوز اضافه نشده است.
4. منطق Swing و استراتژی تا نهایی‌شدن تعریف‌ها وارد نشده است.
5. Session برابر Asia/Tehran، از 07:00 شامل تا 23:00 غیرشامل است.
6. خارج از جلسه، داده همچنان در Replay ثبت می‌شود اما با `inside_session=false` علامت می‌خورد؛ این امکان برای تحلیل زمینه‌ای لازم است.

## اصل ضد نگاه به آینده
هر رویداد فقط در زمان خودش به مصرف‌کننده تحویل داده می‌شود. ترتیب قطعی:
`timestamp -> timeframe priority -> source row`
در صورت برابر بودن timestamp، ترتیب تایم‌فریم H1 سپس M15 سپس M1 است.
